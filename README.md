# GUOFLIX 线路配置

电视端会定期读取 [`playback-routes.json`](./playback-routes.json)，也可以在“设置”中选择“刷新线路配置”立即更新，无需重新安装 APK。

## 2026-10-28 播放说明

上游已开始拒绝本地随机生成的匿名 `device_id/iid`，表现为接口连通但返回 `HTTP 200 + 0 字节`。这不是换 `a/b` 域名可以解决的问题。

GUOFLIX 0.14.0 改为每台电视首次启动时向官方设备注册服务申请自己的游客设备身份，并在 `sinfonlinea` / `sinfonlineb` 两个官方高清节点之间自动切换、失败节点冷却 5 分钟；两者均不可用时仍会回退官网兼容线路。设备身份只保存在电视本机，不写入本仓库，也不需要手机号或账号密码。

0.13.x 及更早版本无法仅靠刷新 JSON 绕过这次身份策略调整，需要覆盖安装一次 0.14.0；之后普通域名和请求参数变化仍可继续通过本仓库远程更新。

## 更新方法

1. 打开 `playback-routes.json`，点击铅笔图标编辑。
2. 修改线路参数，并把 `revision` 增加到一个更大的整数。
3. 提交更改。
4. 在电视端进入“设置”，选择“刷新线路配置”。

`schema: 2` 支持把 `single.mode` 在 `single`（单集接口）与 `multi`（多集接口）之间切换。该能力需要 GUOFLIX 0.13.4 或更高版本；旧版会安全地忽略 schema 2 配置。

## 安全限制

APK 只接受固定格式、固定参数字段和内置白名单域名的配置。远程文件不能执行代码，也不能把播放请求重定向到任意域名。无效或旧版本配置会被拒绝，并继续使用上一次可用配置或 APK 内置配置。
